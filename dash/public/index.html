Dynamic Plugins

Drop these anywhere in your Name, Details, or State fields. The RPC re-renders every 15 seconds automatically.

<time:IST>
Live clock in any timezone. Try UTC, IST, America/New_York
<date>
Today as YYYY-MM-DD. Use <date:DD/MM/YYYY> for a custom format.
<uptime>
Bot session uptime. Shows as 3h 42m and increases every minute.
Example: Set details to <time:IST> · grinding ranked → shows "11:47 PM · grinding ranked" and updates live.
